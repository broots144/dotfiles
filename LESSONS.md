# Lessons

One line per lesson, newest first.

- 2026-11-08: book was offline during the herdr rollout, so `herdr --remote n0` there refused with 'missing': `dot` does not pull the repo, so a Mac that missed a change needs `git -C ~/.dotfiles pull --ff-only` before `dot`. Check every Mac after a rollout, not only n0.
- 2026-11-08: A herdr test session started in Phase 0, before `herdr/config.toml` was linked, ran with herdr's defaults and kept fetching agent-detection rules from herdr.dev into the cache every session shares, so the pinned default server ran remote rules despite `manifest_check = false` (found by security audit run-5). Rule: stop throwaway sessions as soon as the test is done, and treat any herdr state shared across sessions as written by the least-configured one (D-012).
- 2026-11-07: The ignored-file scan found checkouts with `find -name .git -type d`, so git worktrees and submodules (a `.git` file) were never scanned and their gitignored files reached the plaintext mirror. Rule: enumerate working trees by `.git` of either type; keep `-type d` only where an object store is needed (bundles, .git/config).
- 2026-11-07: macOS openrsync cannot delete an excluded package directory (.app, .bundle) held in iCloud Drive and aborts the whole transfer on one evicted file (EDEADLK). Rule: after an rsync failure into iCloud, remove the paths it named with rm and run it again, bounded; and before rsync, remove evicted (dataless) mirror files that changed, because each one aborts the run when rsync tries to read it back.
- 2026-11-06: install-launchd.sh matched host markers with `grep -w`, and '-' is not a word character, so host n0 matched a marker naming n0-2 (the Bonjour rename of 2026-10-28). Rule: match host names as whole space-separated tokens, never with grep -w or a regex.
- 2026-11-06: The iCloud mirror skipped gitignored directories entirely, so their contents (TV tokens, private/ dirs) went to iCloud in plaintext; and under `set -e` one failed probe or iCloud write ended the backup silently. Rules: default-deny means every gitignored path gets an exclude rule, whatever its size or type; a backup script's probes and writes into iCloud must fail into a status code, never into an abort.
- 2026-11-06: The nightly iCloud backup on n0 died on "Resource deadlock avoided" writing a small `.refs` file into iCloud Drive. The iCloud file provider can refuse a write transiently; any write into iCloud Drive needs to tolerate a retry, and one failed file must not abort the whole run. (Open in STATE.md.)
- 2026-10-28: Bonjour renamed n0's LocalHostName to n0-2 on a name conflict and the host-gated LaunchAgents stopped matching. Rule: host identity is `HostName`, else `LocalHostName`.
- 2026-10-28: dev-icloud-backup broke under launchd because macOS `/bin/bash` is 3.2, where an empty `"${arr[@]}"` under `set -u` is an unbound variable. Rule: launchd scripts target bash 3.2.
- 2026-10-28: dev-pull held a checkout forever when origin added a file that already existed untracked locally. Rule: identical untracked copies are dropped, differing ones block, and a checkout stuck for a day fails the sync loudly.
- 2026-10-14: n0 was behind GitHub on six repos while holding nothing unpushed, because it only mirrored the other machine. Rule: GitHub is the hub for ~/dev on both machines (sublevel ADR-071).
- 2026-09-28: The prompt and git helpers ran inside arbitrary repos and honoured their repo-local filter, fsmonitor and other executable config. Rule: every git call in prompt or helpers isolates repo-local executable config; repo data is data (PR #4 to #7).
- 2026-09-27: The iCloud mirror of ~/dev copied secret files (tfvars, .env, keys) in plaintext into iCloud Drive. Rule: secret-shaped or gitignored files go only into an age-encrypted archive (PR #3). No public exposure; the copies were in the operator's own iCloud.
- 2026-09-26: `./bin` first in PATH let any cloned repo run code through the prompt helpers, and the unattended Brewfile publisher could push unrelated local commits. Rule: no relative PATH entries; unattended pushes only when their own commit is the single unpushed one (PR #1, #2).
